CodeAlpha AI Chatbot

About the Project

This project is developed as part of my Java Programming Internship at CodeAlpha.

The AI Chatbot is a Java Swing-based application designed for interactive communication using predefined FAQ responses and text similarity matching.

Features

- Futuristic animated dashboard
- Interactive chatbot interface
- FAQ Knowledge Base
- Chat History
- Rule-based and similarity-based response matching

Technologies Used

- Java
- Java Swing
- NLP concepts
- Text similarity matching

How to Run

Compile:

javac AIChatbot.java

Run:

java AIChatbot
